# Nepal Travel Landing Page

A static travel landing page for Nepal with a public-shareable design and planner section.

## Local preview

Open the project folder and run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Deploy to Netlify

1. Push this folder to GitHub.
2. Import the repository in Netlify.
3. Set the publish directory to the project root.
4. Deploy.

The included `netlify.toml` handles direct-link routing for a static single-page site.
